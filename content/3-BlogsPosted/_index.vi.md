Dưới đây là tổng hợp các bài viết chia sẻ kiến thức kỹ thuật chuyên sâu về AWS Cloud, AI/ML và DevOps đã được đăng tải trên cộng đồng **[AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj)**:

---

### 1. [Blog 1 - Amazon Bedrock vs Amazon SageMaker: Đâu là giải pháp AI phù hợp cho hệ thống của bạn?](3.1-Blog1/)
Phân tích chuyên sâu và so sánh trực quan hai dịch vụ AI cốt lõi trên AWS: Amazon Bedrock (Serverless Foundation Models) và Amazon SageMaker (Vòng đời ML/DL chuyên sâu). Giúp lập trình viên và kiến trúc sư lựa chọn đúng giải pháp tối ưu cho bài toán ứng dụng AI.

---

### 2. [Blog 2 - Tự động hóa xử lý sự cố CI/CD với AWS DevOps Agent và GitHub](3.2-Blog2/)
Giới thiệu giải pháp ứng dụng AI Agent trong luồng CI/CD. Khám phá cách AWS DevOps Agent kết hợp với GitHub Actions tự động phân tích nguyên nhân gốc rễ (Root Cause Analysis - RCA) và gửi chỉ dẫn sửa lỗi trực tiếp vào Pull Request, giúp giảm chỉ số MTTR từ hàng giờ xuống vài phút.

---

### 3. [Blog 3 - Tối ưu CloudWatch Alarms: Biến tiếng ồn thành những cảnh báo có giá trị](3.3-Blog3/)
Áp dụng mô hình **"3 Right"** (Right Data, Right Context, Right Actions) của AWS để giải quyết triệt để tình trạng spam cảnh báo rác (*alert noise*). Hướng dẫn truy vấn SQL động với Metrics Insights, đính kèm liên kết Runbook/Dashboard và tự động hóa khôi phục (Auto-remediation) qua Lambda & EventBridge.

---

### 4. [Blog 4 - Bảo vệ dữ liệu nhạy cảm trong Logs: Bài học khi tìm hiểu AWS CloudWatch](3.4-Blog4/)
Giải pháp bảo vệ dữ liệu khách hàng riêng tư (PII, số thẻ ngân hàng, Token) trong log ứng dụng bằng tính năng **CloudWatch Logs Data Protection**. Tự động nhận diện và làm mờ (Real-time Masking) dữ liệu nhạy cảm bằng Machine Learning mà không cần sửa code ứng dụng hay cản trở quá trình debug của Developer.
