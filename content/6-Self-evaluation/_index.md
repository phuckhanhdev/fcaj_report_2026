During my internship at **Amazon Web Services Vietnam Co., Ltd.** under the **First Cloud AI Journey (FCAJ 2026)** program from **June 15, 2026** to **August 15, 2026**, I had the privilege to learn, practice, and apply university knowledge to real-world cloud engineering.

I participated in the full-stack development and production deployment of **LifeSync AI Calendar**, a scientific AI-powered smart scheduling web application. My main technical contributions included:
- Architecture design and server provisioning on **Amazon EC2** (Ubuntu 24.04 LTS, Elastic IP, Nginx reverse proxy, PM2 process management, 2GB Swap memory).
- Relational database schema design and migration on **Amazon RDS MySQL**.
- Direct-to-S3 avatar image upload implementation using **Amazon S3 Presigned URLs**.
- Performance acceleration and security hardening using **Amazon CloudFront CDN** and **AWS WAF** (Web ACL with OWASP Top 10 Core Rules and SQL Injection protection).
- Building automated weekly CGV cinema scraping workflows via **AWS Lambda** and **Amazon EventBridge Scheduler**.
- Integrating a resilient **Dual-AI Engine architecture** combining **Google Gemini 2.5 Flash** and **Amazon Bedrock**.
- Automating deployment pipelines with **GitHub Actions CI/CD**.
