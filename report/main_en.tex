\section{Summary}

\subsection{Key Technical Skills \& Knowledge Acquired}
Throughout the 8-week internship at \textbf{Amazon Web Services Vietnam Co., Ltd.} under the \textbf{First Cloud AI Journey 2026 (FCAJ)} program, the student acquired extensive hands-on experience and industry-standard skills:
\begin{itemize}
    \item \textbf{Cloud Infrastructure \& DevOps}: Provisioning, operating, and managing \textbf{Amazon EC2} Ubuntu 24.04 LTS servers, Elastic IP binding, Nginx Reverse Proxy, Gzip compression, Swap memory, PM2 process management, relational database management on \textbf{Amazon RDS MySQL}, and CI/CD pipelines via \textbf{GitHub Actions}.
    \item \textbf{Security \& Global Distribution}: Deploying \textbf{Amazon CloudFront} CDN paired with \textbf{AWS WAF} (mitigating OWASP Top 10 vulnerabilities and SQL Injection), and secure direct uploads via \textbf{Amazon S3 Presigned URLs}.
    \item \textbf{Serverless \& Automation}: Developing \textbf{AWS Lambda} functions combined with \textbf{Amazon EventBridge Scheduler} for automated weekly CGV cinema data crawling.
    \item \textbf{Artificial Intelligence (AI Engine)}: Designing a resilient \textbf{Dual-AI Engine} architecture integrating \textbf{Google Gemini 2.5 Flash} and \textbf{Amazon Bedrock}.
\end{itemize}

\subsection{Personal Reflections on the Company \& Program}
\begin{itemize}
    \item \textbf{Work Environment}: The corporate culture at AWS Vietnam is exceptionally open, professional, and fosters a strong Root Cause Analysis mindset.
    \item \textbf{Mentor Guidance}: The direct industry supervisor provided invaluable guidance, architecture review, and continuous support to empower student learning.
    \item \textbf{Practical Value}: The internship bridged the gap between academic theories and enterprise reality, enabling the student to deploy a full-stack product into production (\url{https://phuckhanh.id.vn}).
\end{itemize}

\subsection{Future Improvement \& Career Development Goals}
\begin{itemize}
    \item Deepen knowledge in Cloud Security and enforce IAM Least-Privilege access principles.
    \item Expand Infrastructure-as-Code (AWS CDK / Terraform) adoption to automate disaster recovery workflows.
    \item Pursue a professional career path as a Cloud Architect / DevOps Engineer.
